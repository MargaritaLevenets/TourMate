# components/

Окремі цеглинки інтерфейсу — те, з чого складаються екрани.

## Що сюди класти

Один файл на компонент. Усередині:

- **навіщо він** і де застосовується
- **стани**: звичайний, натиснутий, вимкнений, завантаження, помилка, порожній
- **розміри й варіанти**, якщо їх кілька
- **які токени** використовує (посилання на [`../tokens/`](../tokens/))
- **правила доступності**: мінімальний розмір зони натискання, контраст, підписи

## Ймовірний список

Уточниться після вайрфреймів:

```
button.md
input.md
tour-card.md          картка туру в списку розкладу
tourist-row.md        рядок туриста в записі на тур
bottom-nav.md         нижня навігація по чотирьох розділах
date-picker.md
empty-state.md
```

## Правило для мобільного

Зона натискання — **не менше 44×44 пікселів**. Гід тицяє пальцем на ходу,
а не мишкою за столом.

## Статус

Порожньо — компоненти виділяємо з вайрфреймів, коли стане видно, що повторюється.
