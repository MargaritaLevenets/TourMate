# TourMate

Веб-застосунок-помічник для приватного екскурсовода: розклад, тури, туристи
й матеріали — в одному місці, у телефоні.

**Стан:** ідея описана, структура репозиторію готова, дизайн ще не починався.
**Платформа:** веб-сайт під телефон (mobile-first), без встановлення.
**Мова інтерфейсу:** українська.

Повний опис ідеї — [idea.md](idea.md) ([сторінкою](idea.html)).
Інструкції для Claude Code — [CLAUDE.md](CLAUDE.md).

---

## Чотири розділи застосунку

Порядок — це черга роботи, а не просто список.

| # | Розділ | Про що | Стан |
|---|---|---|---|
| 1 | **Розклад** | календар турів, записи туристів, нагадування | ⬜ наступний в роботу |
| 2 | **Тур наживо** | маршрут по точках, тексти й підказки на екскурсії | ⬜ не почато |
| 3 | **Матеріали** | фото, факти, посилання, нотатки до турів | ⬜ не почато |
| 4 | **Клієнти й гроші** | картки туристів, оплати, підсумки заробітку | ⬜ не почато |

## Де що лежить

Шлях роботи зліва направо: спершу дізнаємося → потім вирішуємо структуру →
потім вигляд → потім розкладаємо на деталі → потім віддаємо в розробку.

| Папка | Що там | Стан |
|---|---|---|
| [`research/`](research/) | дослідження: інтерв'ю, конкуренти, сценарії | 🟡 конкуренти визначені, інтерв'ю немає |
| [`research/screens/`](research/screens/) | скриншоти чужих застосунків | ⬜ порожньо |
| [`wireframes/`](wireframes/) | чорно-білі схеми екранів: що де стоїть | ⬜ порожньо |
| [`concept/`](concept/) | візуальний напрям: настрій, референси, пробні екрани | ⬜ порожньо |
| [`tokens/`](tokens/) | кольори, шрифти, відступи, радіуси — як значення | ⬜ порожньо |
| [`components/`](components/) | кнопки, картки, поля, навігація | ⬜ порожньо |
| [`design-system/`](design-system/) | правила: сітка, типографіка, стани, доступність | ⬜ порожньо |
| [`handoff/`](handoff/) | що віддаємо в розробку: специфікації, експорти | ⬜ порожньо |

У кожній папці лежить свій `README.md` — там детально, що саме туди класти.

## Наступні кроки

1. Провести 2–3 інтерв'ю з гідами → записати в [`research/`](research/)
2. Зробити вайрфрейми розділу **Розклад** → [`wireframes/`](wireframes/)
3. Обрати візуальний напрям → [`concept/`](concept/)
4. Витягнути з напряму токени → [`tokens/`](tokens/)

## Як користуватися репозиторієм

- **Файли — у Markdown** (`.md`), демо й прототипи — самодостатній HTML одним файлом.
- **Назви файлів — латиницею**, малими літерами, через дефіс: `tour-live-map.md`.
  Вміст файлів — українською.
- **Цей README — живий індекс.** Додала файл — онови тут рядок і стан.
  Індекс, який застарів, гірший за його відсутність.
