# tokens/

**Токени** — це назви для значень дизайну. Замість «сірий #6B7280» кажемо
`color-text-muted`. Замість «16 пікселів» — `space-4`.

Навіщо: коли треба змінити колір тексту, ти міняєш його в одному місці,
а не шукаєш по всіх макетах.

## Що сюди класти

| Файл | Про що |
|---|---|
| `colors.md` | кольори: фон, текст, акцент, стани помилки й успіху |
| `typography.md` | шрифти, розміри, насиченість, міжрядковий інтервал |
| `spacing.md` | відступи — драбинка значень (4, 8, 12, 16, 24, 32…) |
| `radius.md` | заокруглення кутів |
| `elevation.md` | тіні й шари |

## Правило іменування

`категорія-роль-варіант`, латиницею через дефіс:

```
color-bg-base
color-text-primary
color-text-muted
color-accent
space-4
radius-card
```

Ім'я описує **роль**, а не вигляд: `color-accent`, а не `color-orange`.
Якщо акцент колись стане синім, назва не збреше.

## Головне правило

Токени — джерело правди. Кольори й відступи не вписуються прямо в компоненти
й макети, якщо їх можна взяти звідси.

## Статус

Порожньо — токени з'являться після того, як буде обрано візуальний напрям
у [`../concept/`](../concept/).
