# handoff/

Те, що віддається в розробку. Мета: розробник відкриває папку й може працювати,
не ставлячи питань і не відкриваючи Figma.

## Що сюди класти

- **специфікації екранів**: розміри, відступи, поведінка, що при натисканні
- **експорти**: іконки (SVG), зображення, шрифти
- **перелік станів** для кожного екрана: завантаження, порожньо, помилка
- **нотатки для розробника**: крайні випадки, обмеження, що можна спростити

## Як називати файли

За розділом і екраном, так само як у вайрфреймах:

```
schedule-month.md
schedule-day.md
icons/
```

## Чекліст перед передачею екрана

- [ ] описані всі стани, включно з порожнім і помилкою
- [ ] усі кольори й відступи вказані **іменами токенів**, не числами
- [ ] зазначено, що відбувається при натисканні на кожен елемент
- [ ] зазначено, звідки беруться дані на екрані
- [ ] іконки експортовані в SVG
- [ ] перевірено на вузькому екрані (375 пікселів завширшки)
