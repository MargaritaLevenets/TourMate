# research/

Усе, що ми **дізналися** про гіда та його роботу.

- [`research.md`](research.md) — головний файл: питання, інтерв'ю, конкуренти, сценарії, висновки
- [`screens/`](screens/) — скриншоти чужих застосунків для аналізу конкурентів

## Що сюди класти

- нотатки з розмов із гідами (`interview-01.md`, `interview-02.md`, …)
- розбір конкурентів
- спостереження й цифри

## Чого сюди не класти

Ідей і рішень. Дослідження — про те, **як є**. Як має бути — це `concept/`
і `wireframes/`.
