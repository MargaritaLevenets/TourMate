# wireframes/

Чорно-білі схеми екранів: **що де стоїть**. Без кольору, без шрифтів, без краси —
на цьому етапі вирішуємо структуру, а не вигляд.

## Що сюди класти

- схеми екранів (експорт із Figma або самодостатній HTML одним файлом)
- опис екрана текстом: що на ньому, що звідки береться, що станеться при натисканні
- порожні стани та стани помилки — вони теж екрани

## Як називати файли

`розділ-екран`, латиницею через дефіс:

```
schedule-month.md
schedule-day.md
schedule-tour-card.md
tour-live-route.md
```

## Порядок роботи

Йдемо розділами, а не всіма екранами одразу:

1. **Розклад** ← починаємо тут
2. Тур наживо
3. Матеріали
4. Клієнти й гроші
